## Objective
Iris has unit tests but no script to run them, and AGENTS.md only lists dev/build. Agents dispatched
to this repo cannot verify their own changes. Add `pnpm test` and `pnpm typecheck`, and list them in
AGENTS.md so every future issue can rely on them.

## Context
- `package.json` — `scripts` has `dev`, `build`, `bundle-skills`, `lint`, ... but no `test` / `typecheck`.
- Test files (Node test runner via `tsx`): `src/agent/repairMessages.test.ts`,
  `src/lib/liftToolImages.test.ts`, `src/lib/pageTools.eval.test.ts`.
  Today they run with `pnpm exec tsx --test 'src/**/*.test.ts'` (9 tests pass).
- `tsconfig.json` is a solution file referencing `tsconfig.app.json` and `tsconfig.node.json`;
  `build` already type-checks with `tsc -b`.
- `src/agent/builtinSkills.json` is gitignored and generated by `pnpm bundle-skills`; `tsc -b` needs it,
  which is why `dev` and `build` run `bundle-skills` first.
- `AGENTS.md` (`CLAUDE.md` is a symlink to it) — "Quick Reference" section.
- `services/relay/` is a separate package with its own `test` script; out of scope here.

## Tasks
- [ ] Add `"test": "tsx --test 'src/**/*.test.ts'"` to `package.json` scripts.
- [ ] Add `"typecheck": "pnpm bundle-skills && tsc -b"` to `package.json` scripts.
- [ ] Add `pnpm test` and `pnpm typecheck` lines to AGENTS.md "Quick Reference", matching the existing bullet style.

## Acceptance
- [ ] `pnpm test` runs all three test files and reports 9 passing tests.
- [ ] `pnpm typecheck` exits 0 on a fresh checkout where `src/agent/builtinSkills.json` does not exist yet.
- [ ] A new `src/**/foo.test.ts` would be picked up without editing the script (glob, not a file list).
- [ ] AGENTS.md shows both commands; `CLAUDE.md` still resolves to the same file.

## Boundaries
- Always: keep `build` and `dev` unchanged.
- Never: add a test framework or dependency (`tsx` and the Node test runner are enough); never `git commit` (AGENTS.md rule).
- Ask: if any existing test fails, report it instead of editing the test.
