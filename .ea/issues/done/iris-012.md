## Objective
Slash commands and skills were two overlapping systems. Make skills the only one: stored in
extension storage, invoked with `/name`, listed on a Skills tab, and editable by the agent.

## Context
- `src/lib/skillStore.ts` — `iris_skills` records (virtual directories of files).
- `src/sidepanel/components/SkillsTab.tsx` — list, toggle, delete, preview every file.
- `src/sidepanel/components/ChatInput.tsx` — `/` menu over enabled skills.
- `src/sidepanel/components/TabSwitcher.tsx` — Agent, History, Skills, Scripts in front; the rest in a menu.
- `skills/summarize/SKILL.md` — former `/summarize` command.
- `scripts/bundle-skills.ts` → `src/agent/builtinSkills.json` (generated, gitignored).

## Tasks
- [x] Store skills in `chrome.storage.local`; drop `commandStorage`, `slashCommands`, and the linked folder.
- [x] Port `/summarize` to a skill.
- [x] `/name args` sends the whole line; Enter completes the name only while the menu is choosing.
- [x] Add the Skills tab with previews of every file, not only `SKILL.md`.
- [x] Move Tabs / Bookmarks / Reading / Notes into a secondary menu.
- [x] Stop tracking the bundled skill JSON.

## Acceptance
- [x] `/summarize extra text` loads the skill and passes the extra text.
- [x] A skill's `reference.md` can be opened from the Skills tab.
- [x] `src/agent/builtinSkills.json` is regenerated by `dev` / `build` and not in git.

## Outcome
Status: done, shipped in 0.4.1. Commits `040677f`, `b374a88`, `268214b`, `342042a`.
