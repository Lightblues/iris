```sh
# 裁切的真正原因
  Radix ScrollArea 的 Viewport 内部会自动包一层 div,并给它 inline style display: table; min-width: 100%。这让子内容的宽度不再受 viewport 限制 —
  所以气泡的 max-w-[92%] 是相对于「内容自然撑开后的总宽度」算的,导致它比可视区还要靠右。Tailwind 的 ! 修饰符无法打败 inline style(优先级一样)。
```
